# v0.1.0 — Read-only SDK preview

This initial release provides a **host-tested Java SDK and Android sample source**, not an APK or a hardware-verified camera application.

## Included

- Reflection-only `org.openpmca.framework.PmcaRuntime.inspect()` and immutable runtime/probe snapshots.
- Sony Scalar, generic Android, plain-host and detection-failure classifications.
- Model, camera firmware, Sony platform version and Android API level observations with explicit `AVAILABLE`, `UNAVAILABLE` or `UNKNOWN` states and fixed diagnostic reasons.
- Reader-local error handling for missing/blocked symbols, empty values, native/linkage failures and unsupported instance members, without discarding successful sibling reads.
- Dependency-free host tests and the minimal `Hello Camera` activity/formatter source.
- Source manifest with minimum/target API 10, one launcher activity, and zero permissions or broadcast receivers.

The SDK does not collect serial numbers, allocate camera hardware, change settings, execute arbitrary scripts, access the network, write device storage or duplicate the desktop USB installer.

## Assets

- `framework.jar`: SDK classes only; no Sony/Android implementations, sample classes, fixtures or host-test code.
- `SHA256SUMS`: checksum for the SDK JAR.
- GitHub-generated source ZIP/tarball for the exact `v0.1.0` tag, including the test sources and sample source.

The Java library JAR is **not installable as a camera APK**. Add it to a consuming application's dependencies.

## Host verification

```bash
./gradlew --offline --rerun-tasks check :framework:jar
./sample/test-host.sh
```

- All 17 core scenarios pass, including four instance-member cases in the final scenario.
- All eight formatter groups pass against the actual SDK JAR.
- Different-working-directory execution and expected missing-JAR failure checks pass.
- Frozen public API, source-manifest metadata, Java 7 class-file target (major 51), and production JAR boundaries pass inspection.
- Independent review's one confirmed reader-isolation finding was fixed with RED/GREEN regressions; the original failure reproducers and whole suites were rerun.
- Supplementary legacy-signature compilation passes for the seven SDK/sample production types, but is not a comprehensive Android API or runtime audit.

Offline build requires the pinned Gradle distribution and JDK 17 compiler to be locally available. With an empty cache the wrapper may download Gradle before Gradle processes `--offline`. Expected obsolete Java 7 source/target warnings are documented.

## Not verified / not shipped

- Comprehensive Android API-signature audit and Dalvik/DEX execution: **NOT RUN**.
- Binary Android resource/manifest compilation and APK assembly: **NOT RUN**.
- APK alignment and minimum-API-10-compatible v1 RSA signing: **NOT RUN**.
- Camera installation, launch, property reads, MENU exit and physical compatibility: **NOT RUN**.

No APK is attached. Provider/method presence and passing host tests are not hardware compatibility claims. Use the [manual smoke-test protocol](../testing/read-only-camera-smoke-test.md) only after separately building and validating an APK.
